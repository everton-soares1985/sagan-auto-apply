  - Um input customizado é criado no lugar
  - Playwright não conseguia interagir com elementos invisíveis
  - A biblioteca funciona como autocomplete (digitar + Enter)

  ## 🧩 CONCEITOS TÉCNICOS IMPORTANTES

  ### Selectize.js

  - Biblioteca JavaScript que transforma <select> em dropdowns customizados
  - O select original fica display: none
  - Cria estrutura DOM customizada:

    <select style="display: none;"></select>
    <div class="selectize-control"><div class="selectize-input">
            <input type="text">
        </div>
    </div>

  - Funciona como autocomplete: digitar filtra opções

  - [name="academic-level"] ✅

  Mas precisam usar: [name="X"] + .selectize-control .selectize-input input

  ## 🐛 PROBLEMAS CONHECIDOS E SOLUÇÕES

  ### ❌ Problema 1: "CV não encontrado"

  Causa: Caminho do arquivo inválido ou arquivo não existe
  Solução: Verificar cv_file_path no candidate_profile.json

  ### ❌ Problema 2: "Campos select falharam"

  Causa: Selectize.js não detectado ou input customizado não encontrado
  Solução:✅ JÁ RESOLVIDO pela função fill_selectize_field

  ### ❌ Problema 3: "BOM UTF-8 no JSON"

  Causa: PowerShell adicionou marcação UTF-8 inválida
  Solução: Usar [System.IO.File]::WriteAllText() com encoding UTF8sem BOM

  ### ❌ Problema 4: "Scroll não funciona"

  Causa: elem.scroll_into_view_if_needed() não é suave
  Solução: ✅ Substituído por .evaluate("el => el.scrollIntoView({behavior: 'smooth', block: 'center'})")
